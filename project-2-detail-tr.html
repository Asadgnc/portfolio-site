Proje Adı 2 (Örn: Kişisel Web Sitesi)

Şu anda gezmekte olduğunuz bu portfolyo sitesini, 4 dilde sıfırdan kodladım.

Zorluk

Amacım, yeni öğrendiğim HTML, CSS ve temel JavaScript becerilerimi gerçek dünyaya ait, işlevsel bir projede uygulamaktı. Hedef sadece bir sayfa yapmak değil, üniversite başvurularım için 4 dilli, tam duyarlı ve görsel olarak yaratıcı bir site oluşturmaktı.

Çözümüm

Bu siteyi adım adım geliştirdim. "Önce mobil" (mobile-first) tasarımına odaklanarak, masaüstüne geçmeden önce telefonlarda iyi görünmesini sağladım. Çok dilli bir dosya yapısı uyguladım ve ana sayfada yaratıcı bir dokunuş için `tsParticles` JavaScript kütüphanesini kullandım.

Kullanılan Teknolojiler

  • HTML5 (Semantik)
  • CSS3 (Flexbox, Grid, Animasyonlar)
  • JavaScript (tsParticles kütüphanesi)
  • Git & GitHub Pages (Versiyon Kontrolü & Yayınlama)

Proje Hedefleri

  • Kodlama ve problem çözme becerilerimi kanıtlamak
  • Git ve web sitesi yayınlamayı öğrenmek
  • Profesyonel, 4 dilli bir portfolyo oluşturmak
