Loyiha Nomi 2 (Masalan: Shaxsiy veb-sayt)

Ayni paytda siz ko'rib turgan ushbu portfolio saytini men 4 tilda noldan kodladim.

Muammo

Mening vazifam yangi o'rgangan HTML, CSS va asosiy JavaScript ko'nikmalarimni real dunyo, funktsional loyihada qo'llash edi. Maqsad shunchaki sahifa yaratish emas, balki universitetga kirish arizalarim uchun 4 tilda gaplashadigan, to'liq sezgir (responsive) va vizual ijodiy sayt yaratish edi.

Mening yechimim

Men bu saytni bosqichma-bosqich qurdum. "Avval mobil" (mobile-first) dizayniga e'tibor qaratib, ish stoli versiyasiga o'tishdan oldin uning telefonlarda yaxshi ko'rinishini ta'minladim. Men ko'p tilli fayl strukturasini joriy qildim va bosh sahifada ijodiy teginish uchun `tsParticles` JavaScript kutubxonasidan foydalandim.

Foydalanilgan texnologiyalar

  • HTML5 (Semantik)
  • CSS3 (Flexbox, Grid, Animatsiyalar)
  • JavaScript (tsParticles kutubxonasi)
  • Git & GitHub Pages (Versiyalarni boshqarish va joylashtirish)

Loyiha Maqsadlari

  • Kodlash va muammolarni hal qilish qobiliyatimni isbotlash
  • Git va veb-saytlarni joylashtirishni o'rganish
  • Professional 4 tilli portfolio yaratish
