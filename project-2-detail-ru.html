Название проекта 2 (напр.: Личный веб-сайт)

Этот самый сайт-портфолио, который вы сейчас просматриваете, написан мной с нуля на 4 языках.

Задача

Моей задачей было применить мои новые навыки HTML, CSS и базового JavaScript для создания реального, функционального проекта. Цель состояла не просто в том, чтобы сделать страницу, а в том, чтобы создать 4-язычный, полностью адаптивный и визуально креативный сайт для моих заявок в университет.

Моё решение

Я создавал этот сайт поэтапно. Я сосредоточился на дизайне "mobile-first", убедившись, что он хорошо выглядит на телефонах, прежде чем переходить к десктопам. Я внедрил многоязычную файловую структуру и использовал JavaScript-библиотеку `tsParticles` для творческого подхода к главной странице.

Используемые технологии

  • HTML5 (Семантический)
  • CSS3 (Flexbox, Grid, Анимации)
  • JavaScript (библиотека tsParticles)
  • Git & GitHub Pages (Контроль версий и развертывание)

Цели проекта

  • Доказать мои навыки кодирования и решения проблем
  • Изучить Git и развертывание веб-сайтов
  • Создать профессиональное 4-язычное портфолио
