Project Name 2 (Ex: Personal Website)

The very portfolio site you are currently browsing, coded from scratch in 4 languages.

The Challenge

My challenge was to apply my new HTML, CSS, and basic JavaScript skills to build a real-world, functional project. The goal wasn't just to build a page, but to create a 4-language, fully responsive, and visually creative site for my university applications.

My Solution

I built this site iteratively, step-by-step. I focused on a "mobile-first" design, ensuring it looked good on phones before scaling up to desktops. I implemented a multi-language file structure and used the `tsParticles` JavaScript library for a creative touch on the homepage.

Technologies Used

  • HTML5 (Semantic)
  • CSS3 (Flexbox, Grid, Animations)
  • JavaScript (tsParticles library)
  • Git & GitHub Pages (Version Control & Deployment)

Project Goals

  • Prove my coding & problem-solving skills
  • Learn Git and website deployment
  • Create a professional 4-language portfolio
